## როგორ გავუშვათ GitHub Pages-ზე

1. GitHub-ში გადადით repository → Settings → Pages
2. Source აირჩიეთ: `Deploy from a branch`
3. Branch: `main`
4. Folder: `/root`
5. Save

მას შემდეგ, GitHub დაინსტალაციას გაუკეთებს Pages-ს და შექმნის公開 URL-ს.

## Local preview

Open the file directly in a browser or run a small local server:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
